今作っているプログラムで、ニュースチャンネルの動画一覧を取得するのに以下のようなコードを使っていた。
```js
function getlistid(channelid) {
  let res = YouTube.Channels.list(part = "contentDetails", { id: channelid });
  let listid = res.items[0].contentDetails.relatedPlaylists.uploads;
  return (listid);
}
```
コードを実行した結果、以下のようになった

### 入力
```js
"UCuTAXTexrhetbOe3zgskJBQ"//日テレ
"UCGCZAYq5Xxojl_tSXcVJhiQ"//ANN
"UC1zYGo1jIIjMVDTLL3dydow"//産経
"UCPdGW3HUuZOXlyDbdqZVt8A"//BSフジ
"UC6AG81pAkf6Lbi_1VC5NmPA"//TBS
```
### 出力
```js
"UUuTAXTexrhetbOe3zgskJBQ"
"UUGCZAYq5Xxojl_tSXcVJhiQ"
"UU1zYGo1jIIjMVDTLL3dydow"
"UUPdGW3HUuZOXlyDbdqZVt8A"
"UU6AG81pAkf6Lbi_1VC5NmPA"
```

ここで気づいたのだが、2文字目がCからUになっているだけである。

わざわざYouTubeAPIのリクエスト数を消費して調べるのはもったいないので、以下のように書き換えた。

```js
let listID ="UU" + str.slice(2);
```
