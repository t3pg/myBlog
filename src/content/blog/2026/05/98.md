---
```https://t-log.pages.dev/```から```https://t-3.dev/```へ自動でリダイレクトするようにした。

まず、Cloudflareの管理画面で、ルール → 設定 → 一括リダイレクト → 一括リダイレクトリストの作成、と進み、名前と説明を設定した。

次に、URLを追加する画面で「または、手動で URL リダイレクトを追加します」を選択して、ソース URL とターゲット URL を指定した。

「パラメータを編集する」を開くと、以下の設定が表示された。

:::quote
- [x] クエリ文字列を保存する
- [x] サブドメインを含める
- [x] サブパスの一致
- [x] パス サフィックスを保持する
:::

これらをオンにすると、配下ページやサブドメインでもリダイレクトされるようになる。ステータスコードは `308` に設定した。

次にリダイレクトルールに進み、「保存してデプロイする」を選択することで設定が適用され、`https://t-log.pages.dev/` を開くと自動的に `https://t-3.dev/` にリダイレクトされるようになった。
